# Assinaturas oficiais Happy Boy

Fonte: `Logotipo.pdf`, arquivo original fornecido pela marca.

- `happy-boy-white.svg`: página 83, letreiro horizontal branco sem monograma.
- `happy-boy-black.svg`: página 84, letreiro horizontal preto sem monograma.
- `hb-white.svg`: página 95, monograma branco.

Os SVGs preservam os caminhos, curvas e transformações vetoriais originais do PDF. A exportação remove somente a área transparente externa; não redesenha os símbolos nem substitui o letreiro por uma fonte. As versões branca e preta são aplicações oficiais distintas, sem filtros CSS.

Manual de referência: `Apresentação-Happy Boy-Identidade Visual.pdf`, páginas 16–19 (paleta e Roboto), 22–24 (desenho exclusivo), 26–29 (assinaturas).

Paleta: preto `#000000`, cinza `#969696`, branco `#FFFFFF`, neon `#EBF308`. Manter a proporção dos SVGs.
